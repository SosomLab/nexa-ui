## 4차 (mac · nexa-sql 세션) — 글자 세로 정렬 = 잉크 기준 `DrawCtx::text_center_y`

**원인**(사용자 캡처: Windows는 가운데 · 맥은 위로 치우침 — 접속 창 그리드 행/헤더 · 상태줄 Tab 메뉴): 행 안 글자를 "상자(어센트+디센트) 가운데"나 고정 오프셋으로 놓았다. 실측(15px): Apple SD Gothic Neo 어센트 11.25 · 디센트 3.75 · 상자 = 15(어센트 안 여백 없음) → 상자 가운데에 두면 잉크(숫자 높이 10)가 약 1.7px 위. 맑은 고딕은 어센트 안 여백이 커서 상자 가운데 ≈ 잉크 가운데(우연히 맞아 보임).
**조치**: `DrawCtx::text_center_y(y, h)`(기본 = 상자 가운데) + `RasterCtx` 오버라이드 = **잉크 가운데**(기준선 = 행 가운데 + 숫자 높이/2 · top = 기준선 − 어센트 · 고정폭 줄은 기본 얼굴 기준). 적용: ctxmenu 항목/단축키 · Tree/TreeGrid 셀·헤더 · TabBar 제목 · Checkbox/Radio/Switch 라벨 · Pulldown · ListEditor · IconDropdown · TimeoutButton · 아바타 배지 · FilePicker 라벨/이름 상자. nexa-sql: 접속 창 그리드 행·헤더(고정 −8px 제거) · 결과 그리드 셀·헤더 · 탐색기 행 · 상태줄.
**검증**: clippy ✓ · nexa-ctl 211 · nexa-dlg 3.

## 5차 (mac · nexa-sql 세션) — 하위 메뉴 유실 방지(대각선 이동 유예)

**요청**(nexa-sql 사용자): Copy SQL 하위 메뉴가 공간 부족으로 위로 밀려 열리는 것은 좋다 — 다만 부모 행과 세로가 어긋나면 대각선으로 가는 동안 다른 부모 행을 지나 자식이 닫힐 수 있다.
**조치**(`ctxmenu`): 커서 직전 위치(`last_pos`)로 **자식 쪽으로 움직이는 중**(가로로 자식에 가까워짐 · 부모 행~자식 세로 띠 안)이면 `SUBMENU_GRACE_MS`(400ms) 동안 자식을 유지 · 멀어지는 이동/유예 초과는 종전대로 교체. 테스트 `moving_toward_submenu_keeps_it_open`(자식을 위로 밀어 둔 상황). 하위 메뉴가 화면을 벗어나지 않게 접는 동작(open_at 경계 접기 + 부모 왼쪽 붙임)은 의도된 것.
