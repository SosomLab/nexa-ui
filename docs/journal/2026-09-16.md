- **`nexa-font` 두부(□) 방지** — UI 문자열 기호 32종(`UI_SYMBOLS` · nexa-sql·nexa-ctl·nexa-dlg 리터럴 전수)을 **회귀 테스트**(`ui_and_mono_fonts_cover_all_ui_symbols` · UI·고정폭 체인 모두)로 고정.
  맥 실측: Apple SD Gothic Neo → Apple Symbols → Arial Unicode MS까지 **⏱⏳(U+23F1/23F3)만 없음** → 시스템 본 전수 조사에서 외곽선을 가진 것은 `STIXTwoMath.otf`뿐(Apple Color Emoji = sbix 비트맵 · LastResort = 자리표시) → 후보 추가.
  OS별 2중 그물: 고정 경로 표(Windows `arialuni` · Linux Fedora/Arch/openSUSE 경로 · Symbola) + **`SYMBOL_FAMILIES` 이름 검색**(`find_font_by_family`가 이제 **하위 폴더 재귀**(`SCAN_DEPTH` 3) — Linux `/usr/share/fonts/<종류>/<패밀리>/`). CI ubuntu는 `fonts-noto-core`(Noto Sans Symbols2) 추가. nexa-font 테스트 5.
- **`TreeGrid`/`TreeView` 가로 스크롤 클립**: `paint_tree_cell(cell, clip)` 분리 — 셀 기하는 스크롤만큼 왼쪽으로 밀리되 글자·아이콘·선택 배경은 `clip`(본문) 안에서만 · 셰브론은 온전히 들 때만. 그동안 파일 대화상자 목록이 사이드바 트리 위에 겹쳐 그려졌다(mac 캡처). 회귀 테스트 `horizontal_scroll_never_paints_left_of_bounds`(기록 DrawCtx로 클립·채움 x ≥ bounds.x).
- **`draw_tooltip` 다중 행**: `\n` 줄마다 폭 측정 · 높이 = 줄 수 × 줄 높이(한 줄 상자에 여러 줄을 넣어 nexa-sql 탭 카드가 잘렸다).
- **`Splitter` 컨트롤(신규 `controls/splitter.rs`)**: nexa-sql 설정 창의 인라인 스플리터를 공용화 — `SplitAxis{Vertical,Horizontal}` · `set_rect`(잡히는 띠) · `on_event → SplitEvent{Hover,Start,Drag(축 좌표),End}` · hover = `IntentFade` **Slow(전역 1초)** 손잡이 · 드래그 즉시 최대 · 테스트 2. 커서 모양은 호스트 몫.
- **`FilePicker`** 4건: ① 점 파일 토글 = **Windows에서만**(`DOT_TOGGLE = cfg!(windows)` · unix는 점 = 숨김이라 "Show hidden" 하나 · `show_dot` 강제 켜짐) ② 브레드크럼 루트 = unix `/`(빈 조각이 남던 것) ③ 브레드크럼 첫 우클릭 = 편집 진입만(같은 사건을 상자에 넘겨 편집 메뉴까지 뜨던 것 · 편집 중 우클릭은 메뉴) · **Esc = 취소 + 진입 경로 복원** ④ 확장자 콤보 변경 = **다시 열거**(`reload`) — 필터는 `lister` 열거 단계에서 걸러지므로 캐시 재필터로는 넓어진 필터의 파일이 안 보였다.
- **우클릭 메뉴 토글 켜짐 = Switch 초록**(`switch::ON_GREEN` 공유) — 손잡이 위치만으로는 켜짐이 안 보였다.
