## 1차 (win · nexa-sql 세션에서) — 설계만 · 코드 0

**요청**(사용자): *"다른 앱들과 동일하게 OS별 차이를 주지 않고 동일한 UI · 파일 관리 기능과 파일 Dialog는 크게 개선 · 컨트롤 라이브러리를 만들었으니 일관성 있고 계층 구조로 확장되도록 구성."*

**확인한 사실**: nexa-ui = gfx/ctl/conf/font 4 크레이트 · 컨트롤 17종(tree·scroll·combo·ctxmenu 포함) · dir2 `widgets/{columns,rows,dock,tabbar,menubar}` 미이관(U-2·U-3) · dir2 `fsprobe.rs`(폴더 mtime + 열거 서명 프로브 · X-40/X-44 실측 = 통지 없는 클라우드 폴더까지 잡는 근거) · `shellnotify.rs`(Windows 셸 통지) · clip은 `popup_win`/`settings_win`으로 별도 winit 창 · beep DR-6(커스텀 렌더링 · 플랫폼 테마가 시각 동일성을 못 깨게) · 어느 앱도 아직 자체 파일 대화상자가 없다.

**설계** [20](../20-file-management-and-dialogs.md): 원칙 3(네이티브 대화상자 0 · OS 차이는 `nexa-fs` 한 층 · 원자→조합→조립→앱) · 계층 = `nexa-fs`(places·listing·sort·ops·watch·naming·kind·path — UI 0) → `nexa-ctl` 파일 컨트롤 6종(PathBar·PlacesList·FileList·FileTree·NameBox·FilterCombo) + `Overlay` z 스택 → `nexa-dlg`(Dialog 프레임·MessageBox·Prompt·Progress·FilePicker{Open·OpenMany·Save·Folder}) → 앱. 대화상자 개선 목록(키보드 우선·경로 편집·자연 정렬·필터·저장 검증·다중 선택·최근/즐겨찾기·외부 변경 반영·미리보기·크기 기억·접근성). 모달 = 창 안 오버레이 기본(3-OS 동일) · Progress만 별도 창. 이식 원천 표(dir2 columns/rows/fsprobe/shellnotify · clip popup/settings_win · ctl tree/scroll/combo).

**보정(에이전트 보고 후)**: ① beep ADR-0014(08-18)가 네이티브 파일 대화상자를 결정(구현 0) → 충돌 명기 · D-9 ② dir2 `nexa-vfs`·`nexa-ops`·`nexa-tree`·`pathinput/nav`·`widgets/{pathbar,rows}.rs`가 std 전용 → `nexa-fs`는 신규가 아니라 **추출** ③ beep `Role::Picker` 자체 피커 시제품(용도 8종) · clip은 `sync.file_dir` 타이핑 → 둘 다 `FilePicker` 소비자.
